# 聊天 UI 冒烟测试（本地模拟）

前置条件：按 project.md 启动本地静态页面；Chromium；每条用例打开全新页面。
本计划不评估真实模型、接口或业务回答质量。

## TC-01：发送与生成状态

1. 在“消息”输入“你好”，点击“发送”。
2. 检查生成中状态：显示“正在生成”、发送禁用、停止按钮可见。
3. 等待生成结束：正文为“模拟回复：你好”，状态为“生成完成”，停止按钮隐藏，复制按钮可见。

证据：生成中、生成完成各一张截图。

## TC-02：停止生成

1. 输入“停止测试”并发送，在生成结束前点击“停止生成”。
2. 检查状态为“已停止”，发送按钮恢复可用。
3. 等待超过原定回复时间，确认正文仍为空且没有出现“生成完成”。

证据：等待后停止状态截图。

## TC-03：复制回复

1. 在本地来源授权剪贴板读写，发送“复制测试”，等待完成。
2. 点击“复制回复”。
3. 检查“已复制”提示，读取系统剪贴板，比较为“模拟回复：复制测试”。

证据：复制后截图及实际剪贴板比较结果。读取剪贴板失败时不能仅凭提示判为通过。

## 清理

无后端数据。测试结束关闭本任务页面；如由本任务启动服务器则停止服务器。
